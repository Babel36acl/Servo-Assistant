修复参数快照导出后难以找到文件的问题，并简化通信设置。

- 点击“读取并导出快照”时弹出原生保存窗口，可选择目录和文件名；取消时不执行本次参数读取或文件导出。
- 文件保存成功后显示完整路径，并在参数快照区保留最近成功导出的路径，方便复制和重新导入。
- 覆盖已有文件由保存窗口确认；先完整写入临时文件，再替换目标备份，保存失败明确报错。
- 移除“P300–P302 手册预设”入口，保留波特率、站号、协议、停止位和校验位的直接设置。
- 补齐导出命令的注册和权限，继续只允许本地主窗口调用。

本地验证：前端 23 项通过，Rust 60 项通过、1 项既有测试入口忽略，Clippy 与 Windows 打包通过。Windows 实际界面验证了保存弹窗、取消、自选中文路径保存及重新导入比较（0 项差异）；本轮界面回归使用配置模拟器。

Windows：安装版 EXE / MSI，或解压即用的便携 ZIP。Linux：DEB、RPM、AppImage（均为 x64）。便携版升级时请保留程序旁的 data 文件夹；Windows 便携版需要 WebView2 Runtime。

参数快照文件扩展名为 .servo-snapshot.json；通信录制目录中的 session.json 和 summary.json 不用于参数快照导入。

在线 EtherCAT 需要安装 Npcap；当前监控为非实时 SDO 轮询，不含运动控制。真实磁盘满、物理断电及独立抓包对照尚未验收。
